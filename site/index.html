How the skills connect

A feature moves left to right. Pick a skill to see what it takes in, what it hands on, and the command to run it.

The requirements nobody wrote down

A feature request names what someone cares about. Rate limits, security, and the experience of the person using it often go unmentioned. On a large team, a reviewer who knows the platform catches them. With an agent, that reviewer has to be a skill.

grill asks what you didn't think to answer

It interviews you one question at a time, checks facts in the code itself, and brings you only the real judgement calls.

Each review lens covers one concern

The five review-plan lenses and the five deep-review lenses include security, architecture, and assumptions. Each gets its own fresh-context reviewer, so the author's blind spots don't decide what gets checked.

show-me makes the gaps visible

A diagram or tree of the flow makes a missing step easier to spot than a paragraph does.
