Install skein

Skein installs through each harness's own plugin command. There is nothing to clone and no script to run. All skills load under the skein: namespace, such as /skein:dev-plan.

Choose your harness

Claude Code

/plugin marketplace add vr000m/skein
/plugin install skein@skein

To pick up upstream changes, re-add the marketplace and run the install command again.

Codex CLI

codex plugin marketplace add vr000m/skein --ref main
codex plugin add skein@skein

To update, refresh the marketplace snapshot, then reinstall. Repeating marketplace add does not refresh it.

codex plugin marketplace upgrade skein
codex plugin add skein@skein

Codex conduct and review-gauntlet need spawn_agent and wait_agent. Codex defers some review gates instead of running them; the README lists which.

Pi

Pi gets a subset of the skills. Install a pinned Git revision:

pi install git:github.com/vr000m/skein@COMMIT_SHA

Pin a release

Tracking main follows unreleased commits. To stay on a tagged release, pass its tag to Codex. Tags are on the releases page.

codex plugin marketplace add vr000m/skein --ref vX.Y.Z

On Claude Code, append @vX.Y.Z to vr000m/skein when you first add the marketplace.

Your first loop

Run these in order on a feature branch. Each hands its output to the next.

  1. Write the plan.
    /skein:dev-plan create feature my-feature
  2. Stress-test it. Answer the decisions it raises, then have it audited.
    /skein:grill docs/dev_plans/my-feature.md
    /skein:review-plan docs/dev_plans/my-feature.md
  3. Build it, one clean-context phase at a time.
    /skein:conduct docs/dev_plans/my-feature.md
  4. Verify. Set Review Gates: full in the plan, and conduct will run review-gauntlet for you. Alternatively, run review-gauntlet yourself.
    /skein:review-gauntlet
  5. Bring the docs in line with the diff.
    /skein:update-docs

If a long run is interrupted, add --resume to conduct or review-gauntlet. Do not restart from scratch.
